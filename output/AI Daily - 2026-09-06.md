## AI工具实操/Agent工作流

### [Using Blender with coding agents on macOS](https://simonwillison.net/2026/Sep/5/blender-coding-agents-macos/)
- **来源**：Simon Willison's Blog
- **评分**：7/10
- **标签**：`#Blender` `#coding agents` `#macOS` `#AI工具`
- **摘要**：在 macOS 上让 ChatGPT Codex 等编码代理使用 Blender 只需安装 blender.org 的完整 Mac 应用，然后直接运行“Use the already install /Applications/Blender to render a scene of a pelican riding a bicycle”这类 Prompt；后续还可追加“OK add a background and a lot of flair”“OK make it a whole lot better”让模型迭代画面。整个过程通过 Blender 的 Python API 驱动，最终生成了一张鹈鹕骑自行车的 3D 海边场景图。

### [anthropics/skills](https://github.com/anthropics/skills)
- **来源**：GitHub Trending
- **评分**：7/10
- **标签**：`#Agent Skills` `#Anthropic` `#开源项目` `#Claude`
- **摘要**：Anthropic 公开了 skills 仓库，为 Claude 提供 Agent Skills 的参考实现，包含 SKILL.md 格式的指令、脚本与资源，覆盖创意设计、开发技术、企业沟通及文档处理等场景。仓库中 docx、pdf、pptx、xlsx 技能正是 Claude 文档生成功能背后的实现，供开发者参考；多数技能采用 Apache 2.0 开源，文档类技能为 source-available。该仓库同时发布 Agent Skills 规范与技能模板，可通过 Claude Code、Claude.ai 及 API 调用，帮助开发者构建可复用的动态技能。
