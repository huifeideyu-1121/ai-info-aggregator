- **评分**：8/10
- **标签**：`#AI Agent` `#开源项目` `#科研自动化`
- **摘要**：alphaXiv 发布 OpenResearch（openresearch.sh），一个本地优先的 research agent 工作区，可把 Claude Code、Codex、OpenCode、Cursor 变成能审阅文献、提出假设、运行实验并产出研究成果的研究代理。macOS/Linux 上执行 `curl -LsSf https://openresearch.sh/install.sh | sh` 安装 CLI，再运行 `orx up` 启动本地仪表盘；Windows 需先安装 Git for Windows 使用 beta 版，要求 macOS 11+。该项目已登顶 GitHub Trending
